## 🌍 Deploy (Netlify)

1. [Netlify](https://www.netlify.com/) hisobingizga kiring
2. **Add new site → Import an existing project** ni tanlang
3. GitHub repozitoriyangizni ulang
4. **Deploy site** tugmasini bosing

Har bir `git push` dan keyin sayt avtomatik yangilanadi ✅
